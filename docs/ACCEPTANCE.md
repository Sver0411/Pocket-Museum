# Pocket Museum 验收记录

更新：2026-11-10。环境：macOS、Node.js 22、npm 10、Google Chrome、Playwright 1.56.1。

## 奶油色展馆与七机主题

用户追加六张新参考后，外层 UI 已改为统一的奶油白展馆：两层展台与铭牌、七机配色、SVG 场景、圆角控制面板、浅色弹窗、带机身缩略图的切换菜单。七份独立 HTML 与整合 HTML 继续从同一代码生成。主题说明见 [THEMES](design/THEMES.md)。

实际执行：构建通过、30 项单元测试通过、76 项资源校验通过；新主题下翻盖/平铺、Mii/笔记、媒体、PictoChat、相机/录音、图标重排、外接连接和系统素材专项 13 项通过，另有 2 项首页/六宽度/路由测试复测通过。真实外接 PPSSPP 连接在先前的专项运行中验证，默认测试没有原生模拟器时按条件跳过。

初轮使用系统 Chrome 时出现测试实例异常；已关闭本轮实例、确认日常 Chrome 恢复，随后测试默认改用 Playwright 独立 Chromium。八份大 HTML 的离线验证单独关闭 DOM trace，避免反复记录内嵌图片/音频数据。没有修改或清理个人浏览器资料。

本轮验收按功能组执行，最终 **37 个自动浏览器用例逐项通过**（包含失败修复后的定向重跑），另1个可选原生模拟器联机用例默认按条件跳过；此前已用官方 PPSSPP 1.20.4 单独实测该联机用例。真实 mGBA/DeSmuME 回归额外确认：屏幕常亮权限被拒绝时不再产生未处理的 Promise 错误，接口的拒绝结果仍保留，不伪装权限授予。

生产构建额外检查通过：博物馆、平铺、有效 DS 日期、GB/GBA/NDS 真实核心与即时存档、移动布局，零页面错误、零外部请求。

## 本轮功能与原机校正

本轮已经实际运行：`npm run build`、30 项单元测试、76 个本地资源 SHA-256 校验；外接模拟器专项 3 项通过（18.1 秒），其中真实官方 PPSSPP SDL v1.20.4 回报按钮按下/松开、模拟轴，完成暂停/恢复/主动断开。窗口共享渲染、裁剪和轨道释放用明确的 Canvas MediaStream 测试夹具验证，不冒充原生窗口选择验收。

真实游戏覆盖新增 GB Snake（mGBA，160×144）、JamClown（DeSmuME，单实例256×384输出至两个LCD，真实触摸计分）。两者即时状态回退已验证；非空原生 SRAM 证据仍来自 GBA 的2048，不能把无SRAM的演示当作原生存档通过。

系统页已按官方原生截图/视频重新标定：3DS HOME、亮度浮层、设置根页和数据管理入口；PSP 类别和条目的非均匀位置及背景轮廓；Vita 3-4-3主页、状态栏和LiveArea门板。对应调查在三份 `*_VISUAL_SPEC.md`，**原版字体、全部图标/banner、应用页面与动画没有全部1:1，不以本轮功能测试代替视觉匹配验收**。

本地资源包可载入用户自备合法图标、背景、banner与浏览器字体，公共发行不附带原厂固件美术。PPSSPP 本机图形后端的暂停截图失败已如实反馈，原生窗口共享选择、真实手柄、手机浏览器仍需手动验收。下方0.1.1/0.1.0记录保留作历史基线，不能当作本轮全部用例结果。

## 尚未通过、未声称完成

- **所有机器从外壳到全部内置系统应用的 1:1 复刻未完成。** 目前已经有系统入口、导航和多种实际本地应用功能。原版字体、图标、音效、所有菜单和完整内置应用仍需逐页对齐。
- 外壳为生成图片、DOM/SVG 控件与 CSS 铰链的混合实现，尚未进行 CAD 尺寸、机械行程或真实摄影标定。照片固定光照仍影响动画观感。
- 按用户要求不显示 Nintendo 厂商 Logo，这是与原机严格一致性的明确差异。
- 真实游戏核心接入主页面 GBA 与 GBA SP；其他机型游戏核心和八个 HTML 内的游戏核心均未接入。
- 单文件包含机身与系统 UI，系统设置使用 localStorage；主网页配置/卡带/存档使用 IndexedDB。清理浏览器数据会移除这些内容。
- 语言等选项目前存值但未完成全部行为。摄像头/录音使用浏览器 API，同源聊天使用 BroadcastChannel；网络、USB、原机无线协议、账号和商店没有与原硬件相同的实现。不要把设置值保存或空库页当作整个应用的完成证明。
- 手柄通过标准 Gamepad API 注入验收，未接实体手柄；iOS Safari 尚未实机验证。
- 固定 EmulatorJS 4.2.3 的核心构建缺少精确源码 commit 报告，已经保存构建信息、哈希、许可和源码来源；未声称字节级可复现。
