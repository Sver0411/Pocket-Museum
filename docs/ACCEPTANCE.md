# PocketSP 验收记录

更新：2026-11-10。环境：macOS、Node.js 22、npm 10、Google Chrome、Playwright 1.56.1。

## 实际执行

- `npm run build`：TypeScript、八个单文件 HTML 和 Vite 生产构建通过。
- `npm test`：6 个文件、22 项单元测试通过，包含逻辑输入/实体反馈分离、原生系统状态流、存储、消息协议和独立平铺比例。
- 生产构建额外验收：4173 端口检查 SP 平铺、DS 触屏/平铺/设置、手动日期实际生效与退出设置关机/重开，无页面错误。
- `npm run verify:assets`：37 个固定 ROM、模拟器、素材、许可及源码文件 SHA-256 校验通过。
- `npm run test:e2e`：27 项完整浏览器验收通过（2.9 分钟），含重做后的独立正视平铺。
- 新增的合盖/平铺、媒体、Mii/笔记、同源绘图聊天、浏览器相机/录音与图标换位已经包含在完整 27 项回归中。相机/录音使用 Chrome 虚拟媒体设备，并非物理摄像头验收。
- 最终八个离线文件与翻盖/摇杆复位另外复查 2 项通过（1.1 分钟）；生产构建独立复查通过，无页面错误。

## 尚未通过、未声称完成

- **所有机器从外壳到全部内置系统应用的 1:1 复刻未完成。** 目前已经有系统入口、导航和多种实际本地应用功能。原版字体、图标、音效、所有菜单和完整内置应用仍需逐页对齐。
- 外壳为生成图片、DOM/SVG 控件与 CSS 铰链的混合实现，尚未进行 CAD 尺寸、机械行程或真实摄影标定。照片固定光照仍影响动画观感。
- 按用户要求不显示 Nintendo 厂商 Logo，这是与原机严格一致性的明确差异。
- 真实游戏核心接入主页面 GBA 与 GBA SP；其他机型游戏核心和八个 HTML 内的游戏核心均未接入。
- 单文件包含机身与系统 UI，系统设置使用 localStorage；主网页配置/卡带/存档使用 IndexedDB。清理浏览器数据会移除这些内容。
- 语言等选项目前存值但未完成全部行为。摄像头/录音使用浏览器 API，同源聊天使用 BroadcastChannel；网络、USB、原机无线协议、账号和商店没有与原硬件相同的实现。不要把设置值保存或空库页当作整个应用的完成证明。
- 手柄通过标准 Gamepad API 注入验收，未接实体手柄；iOS Safari 尚未实机验证。
- 固定 EmulatorJS 4.2.3 的核心构建缺少精确源码 commit 报告，已经保存构建信息、哈希、许可和源码来源；未声称字节级可复现。
