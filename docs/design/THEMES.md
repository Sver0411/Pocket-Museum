Stage 8 已将七台机型拆分为独立展示组件：像素框、Y2K 玻璃、银色展台、双屏导引、HOME 磁贴、XMB 导航轴和 LiveArea 气泡。详情见 [七机型展示层](STAGE8_PRESENTATIONS.md)。页面共享基础字体、弹窗和输入状态，各自组织键位与游玩控件。切换掌机菜单带机身缩略图。移动端保留机身中心位置，通过底部操作入口打开设置；背景不接收指针事件。

`ThemeBackdrop.tsx` 为原创 SVG/CSS 场景，`museum.css` 管理外层呈现。机身素材、实体控件几何、翻盖姿态、原生屏幕与模拟核心继续使用已有实现。七份独立 HTML 和整合 HTML 从同一代码生成；没有为离线版本另写一套设计。

首页使用 SVG viewBox 按现有 viewport 裁掉透明边缘，等待图片载入后显示，避免慢速加载时出现半张图片。场景不使用噪点滤镜或循环背景动画。
