# 翻盖与完全展开

2026-11-10。三台翻盖机提供三种姿态：半展开、完全展开、合盖。机身上边缘可点击或拖动开合；侧栏有明确按钮。完全展开/恢复半展开保留当前系统、卡带、游戏 iframe 和存档状态。

## 几何

- `devices.ts` 定义半展开上盖与闭合盖板范围。`flatDevices.ts` 定义三台独立正视机身图片和全新坐标。闭合盖板在 `LidCover.tsx` 中按当前视角绘制：半展开为梯形，正视平铺为矩形。
- DS/3DS 下屏也独立标定了玻璃窗口的四角，屏幕画面和触摸命中跟随窗口的透视，不再把矩形内容直接贴在梯形黑框上。
- 平铺不变形、不拉伸半展开底图。它使用单独生成的正交俯视图；`base-plane` 不施加投影矩阵。圆形 A/B/ABXY 与 3DS 摇杆使用等宽高坐标，十字键有各自的新轮廓，所有按钮和触摸区重新标定。
- 平铺 LCD 按原生比例独立放置：SP 为 3:2，DS 双屏同为 4:3，3DS 为 5:3 / 4:3。`projection.ts` 仅继续用于半展开 DS/3DS 下屏玻璃的四角对齐。
- `--fold` 在 0–1 间驱动开合，盖板围绕下缘旋转。背面使用 `rotateX(180deg)`；与旋转方向匹配，避免沿 Y 翻面导致镜像。
- 银色 SP、白色 DS 和青色 3DS 的背壳分别绘制；不加噪点纹理或厂商 Logo。3DS 保留两枚外侧摄像头，DS 保留双屏形状的型号图形。
- 闭合后整机上移到展示区中心。背壳、底座接缝、铰链与遮蔽分开合成。拖动时直接跟手，释放超过一半吸附到另一姿态；取消操作恢复原姿态。

## 运行状态

- DS / 3DS 合盖进入界面睡眠（当前对应暂停），开盖只恢复由合盖触发的运行；如果此前由用户手动暂停，开盖继续保持暂停。
- GBA SP 没有自动合盖睡眠开关，合盖不会自动暂停真实游戏；遮住屏幕并释放外部输入。需要暂停可用网页暂停按钮。
- 开合和切换视角不销毁游戏 iframe；全展开更换展示素材、尺寸和控件坐标，保留系统与游戏状态。
- 合盖、姿态切换、拖动起始、失焦时释放持有输入；闭合内侧控件不可聚焦。相机、录音和媒体在相关暂停/退出流程中停止或释放资源。

## 验证与限度

Playwright 检查三台机器的盖板位置与标定框误差小于 3 CSS px，拖动开盖、隐藏内部命中区、全展开/半展开切换、手动暂停保留；同时断言平铺确实加载独立图片、底座没有变换、圆键与摇杆宽高相等。真实 mGBA 用例检查平铺后合盖/开盖仍可输入。单元测试检查 LCD 对齐矩阵、独立图片选择和原生屏幕比例。

当前几何与生成的底图对齐；它不等价于对真实硬件完成 CAD 尺寸或运动学标定。完全展开是方便网页游玩的平铺展示方式，不表示三台实机都可安全展开到同一个物理角度。
